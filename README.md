# Fahim — Digital Problem Solver

Phase 1 foundation for Fahim's personal digital HQ.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

Set `NEXT_PUBLIC_SITE_URL` to the real public production origin before production so canonical, sitemap, and robots URLs are absolute. Phase 2 remains gated until verified project and contact content are supplied.

See [`PHASE-1-REPORT.md`](./PHASE-1-REPORT.md) for the completed scope, verification evidence, known limitations, and the Phase 2 approval gate.

Phase 2 source materials and the copy-paste-ready continuation brief are in [`PHASE-2-HANDOFF.md`](./PHASE-2-HANDOFF.md). The three supplied project documents are preserved under `content/project1-doc.json`, `content/project2-doc.json`, and `content/project3-doc.json`; their visual assets are under `public/assets/projects/`.
